
# Hand Gesture Racing Controller

A Python-based computer vision application that allows
users to control existing car racing games using hand
gestures captured through a webcam.

## Project Goal

Build a real-time hand gesture controller that translates
hand movements into keyboard inputs for racing games.

## Planned Features

- Real-time webcam capture
- Hand landmark detection using MediaPipe
- Gesture-based left and right steering
- Acceleration and braking controls
- Gesture smoothing and calibration
- Safe keyboard input handling
- Configurable game key mappings

## Technology Stack

- Python
- OpenCV
- MediaPipe
- Windows keyboard input library
